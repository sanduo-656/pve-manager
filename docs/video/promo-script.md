# PVE 管家宣传视频稿

横版 1920×1080，约 70 秒，适合 B 站投稿。口播语气自然、清晰，音乐轻快且保持低音量。主体画面采用 Android 模拟器录屏，所有资源与监控值均为演示数据；画面右上角持续显示“演示数据”。

## 口播全文

不需要 Google Play 服务，也不用谷歌账号。下载 APK，直接安装 PVE 管家。

统一查看虚拟机和容器，状态、CPU 和内存一目了然。多个连接，也能快速切换。

进入详情，操作更方便。开机、正常关机与重启，查看任务结果和控制台入口。

宿主机资源也能掌握。CPU、内存、根分区与网络，还有负载、交换空间和存储容量。

历史趋势从一小时到一年。网络展示节点汇总采样，磁盘页面展示的是容量。

HTTPS 与证书指纹确认，支持动态验证码登录。默认端口八零零六，认证域 PAM。

画面采用演示数据。当前是测试体验版，支持安卓七及以上。

前往 GitHub 下载体验，搜索 PVE 管家，或访问画面中的地址。

## B 站投稿文案

**建议标题**

不用 Google Play！PVE 管家 v0.4.2，手机管理虚拟机与宿主机监控

**备选标题**

给 PVE 做了个中文 Android 客户端：直接装 APK，资源管理与节点监控都装进手机

**简介**

PVE 管家是一款第三方中文 Android 客户端，面向 Proxmox VE 8/9。无需 Google Play 服务，不要求谷歌账号，从 GitHub 下载 APK 即可安装。

在手机上查看 VM / LXC 状态、CPU 和内存，执行开机、正常关机与重启，跟踪任务结果，并通过入口使用 PVE 自带控制台。节点页提供 CPU、内存、负载、Swap、根分区、节点汇总网络与存储容量，支持从 1 小时到 1 年的历史趋势。

当前版本：0.4.2+7。支持 Android 7.0 及以上，提供测试签名 APK。视频使用演示数据；新增监控及控制台等功能仍需结合真实 PVE 环境进一步验证。网络展示节点汇总 RRD 采样，磁盘监控以容量为主。

源码与下载：https://github.com/sanduo-656/pve-manager

欢迎在 GitHub Issues 提交问题与建议。反馈时请注明应用、Android 与 PVE 版本，并对管理地址、账号及错误日志进行脱敏。
