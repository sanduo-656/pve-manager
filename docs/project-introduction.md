## 一句话介绍

PVE 管家是一款中文 Android 客户端，让你在手机上管理 Proxmox VE 虚拟机与容器，并查看宿主机的性能与容量。

## GitHub 仓库简介

中文 Android Proxmox VE 客户端：多连接、VM/CT 管理、noVNC/xterm.js 控制台与节点性能监控。

## 完整介绍文案

### 把常用 PVE 管理操作放进手机

PVE 管家面向 Proxmox VE 8/9，提供适合 Android 手机和平板的中文界面。你可以保存多个服务器或集群入口，在资源列表中查看 QEMU 虚拟机、LXC 容器的运行状态和 CPU、内存情况，进入详情后执行开机、正常关机或重启，并跟踪 PVE 返回的任务结果。

需要进入系统时，QEMU 使用 PVE 自带的 noVNC，LXC 使用 PVE 自带的 xterm.js。所有数据与操作均受登录账号的 PVE 权限约束。

### 查看宿主机的性能和容量

节点详情增加 CPU 使用率、I/O 等待、系统负载、内存、Swap、根分区及网络概览，并展示各 PVE 存储的容量和可用状态。历史趋势可切换 1 小时、24 小时、周、月和年。

监控直接读取 PVE 自带接口，无需安装额外采集程序。应用在前台查看节点时更新数据，离开详情或退到后台后停止监控轮询。数据缺失会显示未知，接口失败会提示错误并保留上次成功结果和更新时间。

网络是 PVE 提供的节点汇总 RRD 采样，单位为 B/s，界面自动换算；磁盘监控以根分区和 PVE 存储容量为主。目前未包含逐物理磁盘 IOPS、延迟、SMART、CPU 温度或后台持续告警。

### 登录清晰，权限按需配置

登录时只需填写主机名或 IP、用户名和密码。端口默认 `8006`，认证域默认 `pam`，可在高级设置中切换为 `pve` 或自定义认证域；用户名若已包含 `@认证域`，以用户名为准。

应用使用 HTTPS，支持系统可信证书，以及核对后固定自签名证书的 SHA-256 指纹。TOTP 验证码不保存；新建连接默认不记住密码，用户开启后才通过 Android 安全存储保存密码。建议使用专用账号并按需授予读取、控制台或电源操作权限。

### 当前版本与验证范围

当前版本为 0.4.1+6，支持 Android 7.0 及以上，提供内部测试签名 APK。这个版本已完成静态分析、150 项自动化测试、安装包签名与对齐检查，以及 Android API 36 模拟器安装和启动验证。

新增监控在真实 PVE 8/9 上的字段、权限和采样精度仍需进一步验证；真实设备上的控制台、TOTP、长期会话及电源操作也需要结合目标环境确认。介绍图片中的服务器、资源和监控值为演示数据。

## 功能要点

- 中文 Android 界面，支持手机与平板。
- 保存和切换多个 PVE 服务器或集群入口。
- QEMU 与 LXC 资源概览、正常关机、开机、重启及任务结果。
- PVE noVNC 与 xterm.js 远程控制台。
- CPU、负载、I/O 等待、内存、Swap、根分区和网络监控。
- 1 小时、24 小时、周、月、年历史趋势与存储容量列表。
- HTTPS、证书指纹确认、TOTP 与可选的密码安全存储。
- 节点电源操作需要权限和完整节点名确认。

## 功能边界表述

对外介绍时，网络应称为“节点汇总 RRD 采样”，磁盘应称为“根分区和 PVE 存储容量”。当前版本不能表述为逐网卡实时监控、物理磁盘性能或健康检测、后台全天监控与自动告警。验证结果应与真实 PVE 联调范围分开说明。
